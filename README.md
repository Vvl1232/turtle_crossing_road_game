# Turtle Obstacle Game
This is a simple game built using Python's turtle module. The player controls a yellow turtle and must navigate through a field of moving obstacles to reach the top of the screen. With each level, the game becomes more challenging as the speed of the obstacles increases.

Features:
Player Control: Move the yellow turtle forward using the "w" key.
Level Progression: Progress through levels by reaching the top of the screen. Each level increases the speed of the obstacles.
Obstacle Movement: Obstacles move from right to left and reset their positions when they move off-screen.
Collision Detection: The game ends when the turtle collides with an obstacle, and "Game Over" is displayed.
Level Display: The current level is displayed at the top left corner of the screen.
